# Security Policy

## Supported Versions

The package follows semantic versioning. No version is released yet; `main` is supported until 1.0.

Runtime requirements: PHP >= 8.4, Symfony 7.4 / 8.x.

## Reporting a Vulnerability

Do **not** open public issues for security problems. Use:

1. **GitHub Security Advisory** (preferred):
   <https://github.com/msstc4php/vo-base-bundle/security/advisories/new>
2. **Email**: `maxim.shamaev@gmail.com`

Include the bundle, PHP and Symfony versions, a reproducer and the impact. You will get an answer within a week.
